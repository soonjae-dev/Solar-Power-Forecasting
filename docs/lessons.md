# 로컬 및 서버 결과 불일치 원인 분석

## 관찰

로컬 검증을 통과한 변경 다섯 건이 서버에서는 손해로 이어졌다. 그중 세 건은 같은 원인으로 설명된다.

| 변경 | 로컬 | 서버 |
|---|---|---:|
| CatBoost 단독 | 크게 개선 | −141만 원 |
| 예측 수준 ×0.984 | 개선 | −251만 원 |
| 중앙값 모양 배율 | −1.1 \~ −1.7% | −78만 원 |

## 진단 1: 검증 연도의 수준 편향

- 고정 11개월(2024-06 \~ 2025-04)에서 v6의 총량은 실적의 1.013배로 과대예측. CatBoost는 0.997배
- 로컬에서 나타난 CatBoost 우위의 상당 부분은 '예측이 1.6% 낮은' 효과에서 비롯됨
- 평가 연도의 최종 모델에서는 두 모델의 총량 비가 0.998로 차이가 사라짐. 수준을 1.6% 낮춘 제출(8번)은 서버에서 손해였으며, 이는 평가 연도에 과대예측이 없었음을 의미함

## 진단 2: 수준 제거 후에도 남는 차이

- 구간마다 각 모델을 진단용 최적 배율(Σ실적/Σ예측)로 맞춘 뒤 재비교함
- CatBoost+LDAPS는 여전히 4계절 −3.1%로 우세하여, 수준 편향만으로는 설명되지 않음
- 학습 마감이 최근일수록 CatBoost 성능이 악화되는 패턴(p63)을 함께 고려하면, CatBoost의 우위는 해당 1년의 특성에 맞춰진 결과로 판단됨

## 진단 3: '수준 중립' 보정에 숨은 수준 효과

- 중앙값 모양 배율은 총량이 바뀌지 않도록 정규화함. 다만 맑게 예측한 시각, 즉 발전량과 가중치가 큰 시각을 낮추고 흐린 시각을 높이므로, 페널티 기준으로는 수준을 낮춘 효과가 사실상 남음
- 로컬 블록에서 기준 예측에 상수 c를 먼저 곱하여, 서버와 같은 하향 반응(×0.984 → +1.8%)이 나타나는 수준을 구성함. 그 상태에서 규칙 효과를 측정함

| 블록 | 서버형 수준에서의 규칙 효과 |
|---|---:|
| 2022-06 \~ 2023-05 | +1.72% |
| 2023-06 \~ 2024-05 | +0.65% |
| 2024-06 \~ 2025-04 | −0.89% |

- 서버 결과(+0.57%)는 이 범위 안에 위치함
- 모델 6종으로 이전성을 확인하였으나(p91), 모두 같은 1년에서 측정한 결과임. 모델 축의 이전성은 확인하였으나 연도 축의 이전성은 확인하지 못함

## 교훈

1. **검증 연도 분할**: 표본 밖 근거가 한 해에 집중되면, 그해의 수준 편향이 모든 판단에 반영됨
2. **수준 민감도의 별도 측정**: 사후 보정이나 모델 교체를 채택하기 전에, 기준 예측의 수준을 ±4% 변화시켜도 효과가 유지되는지 확인
3. **총량 중립과 페널티 중립의 구분**: 가중치가 큰 시각에 집중된 변경은 총량을 맞춰도 수준 효과를 가짐
4. **정보에서 비롯되는 큰 개선**: 서버에서 확인된 개선의 대부분(+2,832만, +914만, +504만)은 새 정보(특징, GFS)에서 비롯됨. 보정·튜닝·결합의 효과는 수십만 원 단위였으며, 그마저 방향이 불안정함
5. **배정 탐색의 다기간 검증**: 한 구간의 잔차로 찾은 배정은 다른 구간에서 재현되지 않음. 상위 팀은 여러 학습 기간의 교차검증 오차로 탐색함

## 사후 확인: 대회 종료 후 운영팀 공지 (2026-11-14)

대회 종료 후 운영팀이 코드 제출 대상 17팀의 회차별 예측오차율(이용률 10% 이상 시각, 산식 비공개)을 공개하였다. 코드 검증을 마친 상위권 2팀의 방법 요약도 함께 공개하였다.

**상위권 분포**
- 6 \~ 17위는 오차율 3.0 \~ 3.3%로 수렴
- 1 \~ 3위는 마감 직전 한 번의 제출로 2.3 \~ 2.5%까지 급락. 운영팀이 재현성과 누수를 검증 중이므로 비교 기준에서 제외

**검증을 마친 2팀의 공통점**
- 외부 기상 소스 3개를 사용하고, 날짜별 공개 시각이 예측 시점보다 이른지 확인
- 모델은 ML과 DL을 혼합한 앙상블
- 배정은 한 팀이 지역·위도·예보 지점·용량 순 정렬 후 균형 탐색을, 다른 팀이 여러 학습 기간의 교차검증 오차 기반 탐색을 사용

**본 팀과의 비교**
- 오차율이 페널티에 비례한다고 가정하면, 본 팀의 오차율은 약 3.57%. 수렴한 상위권보다 오차가 12 \~ 18% 큼
- 외부 예보를 공개 시각 감사와 함께 사용한 점은 동일. 차이는 모델 구조로, 본 팀은 트리 모델만 사용하였고 DL은 잔차 TCN을 한 차례 시도하는 데 그침
- 따라서 "개선의 상한은 일사 예보의 질이 결정한다"는 판단은 절반만 타당하였음. 하루 안의 연속 구조를 다루는 모델이 격차의 나머지 절반일 수 있음. 다만 공지만으로는 정보와 모델 구조의 기여를 분리할 수 없음
- 오차율이 더 높은데도 순위가 앞선 팀이 있었음. 그 차이는 1 \~ 2%로, 본 팀이 추정한 배정 효과(참조 대비 −1.3 \~ −2.7%)와 같은 규모임. 10% 격차는 설명하지 못하지만, 밀집 구간에서는 수십 계단의 순위 차이로 이어짐
