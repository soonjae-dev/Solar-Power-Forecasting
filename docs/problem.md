# 문제 정의 및 점수 구조 분석

## 과제

- **대상**: 태양광 발전소 253개소, 총 42,655.4 kW
- **구성**: 모든 발전소를 G1 또는 G2에 배정. 평가 1년 동안 배정은 고정이며, 각 집합의 용량 합은 20,000 kW 이상이어야 함. 따라서 한 집합의 용량은 20,000 \~ 22,655.4 kW 범위
- **예측**: 집합별 시간 발전량(kWh) 산출. 예측 시점은 대상일 전날 17:00 KST이며, 대상은 2025-06-01 01:00 \~ 2026-06-01 00:00의 8,760시각
- **입력**: 평가 구간에는 두 제공사의 하루 전 기상 예보와 SMP만 제공. 발전 실적과 실측 기상은 제공되지 않음

## 점수

```
S = Σ_t Σ_g SMP(t)·A_g(t) − 0.1 × Σ_t Σ_g SMP(t)·k(t)·|F_g(t) − A_g(t)|
k(t) = 3  (11 ≤ hour(t) ≤ 15),  그 밖은 1
```

- 첫째 항(매출)은 배정 및 예측과 무관함. 따라서 과제의 핵심은 둘째 항, 즉 **페널티** `W = 0.1·Σ w·|E_g|`(`w = SMP·k`)의 감소
- 두 제출의 차이는 `S_A − S_B = W_B − W_A`로 정확히 계산됨(W에 0.1이 이미 포함됨). 매출의 불확실성이 상쇄되기 때문
- 정규화 점수 `100·(1 − W/W_기준선)`으로 환산하면 공식 기준선 대비 개선율이 됨

## 점수 구조에서 도출한 관찰

**1. 집합 단위 절대오차**

집합 안에서는 발전소 오차가 상쇄되지만, 두 집합 사이에서는 상쇄되지 않는다. 따라서 발전소 단위 RMSE·MAE가 가장 작은 모델과 점수가 가장 높은 모델은 일치하지 않는다.

**2. 배정과 무관한 하한**

발전소별 예측을 고정하면 `E_1 + E_2 = E`(전체 오차 합)는 배정과 무관하다. `|E_1| + |E_2| ≥ |E|`이므로 다음이 성립한다.

```
W ≥ 0.1·Σ w·|E|        (등호: 두 집합 오차의 부호가 같을 때)
```

- 참조 배정은 개발 구간에서 이 하한보다 2.6%만 높음
- 따라서 구성으로 얻을 여지는 작으며, 예측 개선이 우선
- 실제로 정답을 보고 고른 표본 내 최적 배정도 현재 배정보다 1.4%만 낮음

**3. 조건부 중앙값인 최적 점예측**

- 집합 합의 가중 절대오차에서 최적 점예측은 평균이 아닌 조건부 중앙값
- 다만 발전소별 L1 학습으로는 이를 얻을 수 없음. 발전소별 중앙값의 합은 집합의 중앙값과 다르기 때문이며, 실제로 L1과 Huber 모두 성능이 악화됨
- 집합 단위 중앙값 보정은 로컬에서 −1.1%였으나, 서버에서는 기준 수준 편향과 얽혀 손해로 이어짐([lessons.md](lessons.md))

**4. '하루 총량'에 집중된 페널티**

정답 정보로 배율을 맞췄을 때의 감소율이다(진단 전용, 2024-06 \~ 2025-04).

| 맞춘 수준 | 페널티 감소 |
|---|---:|
| 집합별 상수 | −1.2% |
| 월별 | −4.0% |
| 월 × 시각 | −4.7% |
| **일별 총량** | **−47.5%** |

예측에 남은 오차의 절반은 '그날 얼마나 흐린가'의 문제이며, 상수·월별 보정으로 얻을 수 있는 여지는 수 %에 그친다. 이 분해 결과를 근거로 외부 일사 예보 탐색 방향을 결정하였다.
